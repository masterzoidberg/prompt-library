# Roadmap

## Current milestone: Personal V1 release gate

The Personal V1 implementation includes trustworthy local CRUD, metadata, variables, history, bundles, ranked search, command palette, keyboard workflows, responsive accessibility fixes, migrations, and staged backup/restore. Deterministic implementation, clean-install, production-preview, and file-based recovery checks are complete. The remaining release work is the owner-only real-library signoff recorded in [V1_GATE.md](../plan/completion/V1_GATE.md).

## Post-V1 sequence

1. Snapshot reusable blocks and an ordered composer if real workflows justify them.
2. Add a read-only Markdown outline with jump and copy-section actions.
3. Add lightweight related-asset links only if bundles and tags prove insufficient.
4. Explore user-selected automatic backup directories where browser permissions support them.
5. Choose one global-insertion direction (browser extension or desktop wrapper) after a security/access prototype.
6. Consider optional, bounded AI utilities only after local-only workflows are complete and every call is opt-in.

## Explicit non-goals

Accounts, cloud sync, collaboration, public sharing, billing, enterprise governance, prompt execution, a built-in model client, programmable template expressions, nested folders, rich-text storage, telemetry, and mandatory network access are outside this roadmap.
